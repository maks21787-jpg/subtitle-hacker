# Subtitle Hacker

Вивчення англійської (і української) через відео з YouTube. Вставте посилання, слухайте фразу за фразою, зберігайте незнайомі слова, складайте конспект і перевіряйте себе тестом.

## Що вміє

- **Відео + живі субтитри.** Клік по фразі програє її. Повтор фрази ×3 / ×5 / ∞, швидкість 0.5 / 0.75 / 1.
- **Незнайомі слова.** Клік по слову: переклад підставляється автоматично, слово з контекстом потрапляє у ваш словник.
- **Картки.** Повторення за системою Лейтнера, у кожній картці кнопка «почути в оригіналі».
- **Конспект.** Кнопка «+» додає фразу з перекладом, до кожної можна дописати свою думку.
- **Тест по відео.** Переклад слів, пропущені слова на слух, «вгадай наступну репліку».
- **Інфографіка.** Ключові тези відео (виділяються автоматично або з конспекту), статистика, ключові слова. Зберігається як PNG.
- **PDF.** Тези, конспект і словник одним документом.
- Мови відео: англійська (переклад українською) і українська (переклад англійською).

Усі дані зберігаються у вашому браузері (localStorage).

## Як запустити локально

Потрібен [Node.js](https://nodejs.org) 18+.

```bash
node server.js
```

Відкрийте http://localhost:5178. Субтитри підтягуються автоматично за посиланням.

## Як розмістити для всіх

**Vercel (рекомендовано, з автоматичними субтитрами).** Імпортуйте репозиторій на [vercel.com/new](https://vercel.com/new) і натисніть Deploy. Налаштовувати нічого не треба: `index.html` віддається як сайт, `api/subs.js` працює як серверна функція.

**GitHub Pages (без сервера).** Settings → Pages → Deploy from branch → `main` / root. Сайт працюватиме повністю, але субтитри доведеться вставляти вручну: на YouTube «…ще» → «Показати транскрипцію» → скопіювати → «Субтитри вручну». Щоб на Pages субтитри підтягувались автоматично, розгорніть копію на Vercel і впишіть її адресу в `config.js`.

## Структура

| Файл | Що робить |
|---|---|
| `index.html` | увесь інтерфейс і логіка |
| `config.js` | адреса API субтитрів (порожня = той самий сайт) |
| `api/subs.js` | серверна функція: субтитри з YouTube + переклад рядків |
| `lib/youtube.js` | отримання й розбір субтитрів YouTube |
| `server.js` | локальний сервер для розробки |
